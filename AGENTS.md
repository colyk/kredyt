# AGENTS.md

## Project Overview

This page is a personal mortgage planning tool for me and my wife as we plan our dream house.

The UI should feel warm, calm, hopeful, and practical. Avoid generic SEO-style wording like "Kalkulator Kredytu Hipotecznego Polska 2026". Prefer personal, human copy such as "Nasz wymarzony dom", "plan dla nas", and wording that helps us understand whether the house dream is realistic.

Keep the experience simple, private-feeling, and focused on decisions:
- Can we afford the monthly payment?
- How much own contribution do we need?
- When can we reach the savings goal?
- How much do overpayments help?

Do not turn this into a generic finance portal or bank-style landing page.


## Deployment

This project is deployed on GitHub Pages.

Deployment is static: GitHub Pages serves `index.html` directly from the repository.
